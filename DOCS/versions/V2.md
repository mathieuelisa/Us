## Note sur le nommage des futures versions

À partir d'ici, chaque nouvelle version majeure suit le pattern `VX.md`
(`V3.md`, `V4.md`, ...) dans ce même dossier `DOCS/versions/`, avec la même
structure : Contenu ajouté / Hors périmètre / Prérequis techniques / Critères
de sortie / Suite. Voir [03-VERSIONING.md](../03-VERSIONING.md) pour la
convention complète.
