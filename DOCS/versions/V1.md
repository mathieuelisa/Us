# V1.0 — Déblocage premium & module bébé

> Première version "monétisable". S'appuie entièrement sur le [MVP](./MVP.md) :
> ne réouvre aucun chantier des 3 piliers gratuits, ajoute uniquement le
> quatrième pilier et le paiement.

## Contenu ajouté

Correspondance avec le [Design Overview](../01-DESIGN-OVERVIEW.md) :

| Ajouté | Section design | Détail |
|---|---|---|
| ✅ | 1g — Paywall | Intégration paiement réel (achat unique 14,99 €), restauration d'achat, code de réduction |
| ✅ | 8 — Votre bébé | Choix des sections favorites (8y/8a), écran principal (8b), courbe de croissance (8c), ajout mesure/bain/allaitement/biberon (8d/8f/8g/8h) |
| ✅ | Notifications push | Rappels de démarches (5c), gestes du jour (3f), réassurance (4d) — via Expo Notifications + scheduler Supabase Edge Functions |

## Prérequis techniques

- Choix et intégration du provider de paiement (RevenueCat recommandé — cf. [Architecture](../04-ARCHITECTURE.md))
- Table `subscriptions` + vérification serveur du statut premium (jamais uniquement côté client)
- Infrastructure de notifications programmées (cron Supabase ou service externe)

## Hors périmètre (reporté à V2)

- Localisation anglaise
- Thème sombre / couleurs d'accent personnalisées
- Export de données
- Intégration store review native
- Synchronisation temps réel avancée (Realtime Supabase) au-delà du strict nécessaire

## Critères de sortie

- [ ] Achat unique fonctionnel sur iOS (StoreKit) et Android (Play Billing) via le provider choisi
- [ ] Restauration d'achat testée (désinstall/réinstall, changement d'appareil)
- [ ] Les 8 modules bébé persistent correctement et respectent le système de favoris
- [ ] Notifications réellement déclenchées (pas seulement des écrans statiques)
- [ ] Revue App Store / Play Store passée sans rejet lié au paiement ou aux notifications
